## 2024-03-22 - [Interactive Scroll Indicator]
**Learning:** Found a decorative scroll indicator on the home page that looked interactive but wasn't. Making these indicators interactive anchor links (`<a>` tags) with proper `aria-label` and `focus-visible` styles significantly improves both screen reader accessibility and keyboard navigation.
**Action:** When adding animated "scroll down" indicators to hero sections, always implement them as functional anchor links pointing to the next section's ID rather than purely decorative `div`s.
